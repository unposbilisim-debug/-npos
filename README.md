# Yılmaz Elektronik — B2B bayi sitesi (PWA)

Araç ses, multimedya, oto güvenlik ve aydınlatma toptanı.
Bayiler siteden sipariş verir. Patron telefondan barkod okutup fotoğraf çekerek ürün ekler.
Kartlı ödeme **sonraya** bırakıldı.
